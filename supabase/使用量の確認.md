# 無料枠の使用量を確かめる方法

一閃のオンライン機能は Supabase の無料プランだけで動きます。
支払い方法を登録しない限り、自動で有料になることはありません。枠を超えるとメールが届き、猶予期間に入ります。

## いちばん簡単な確かめ方（月に1回くらい）

1. Supabase を開き、左下の歯車（Project Settings）→「Usage」を開く
2. 次の3つを見る
   - **Realtime Messages**: 月200万通まで。一閃でいちばん先に増えるのはここです
   - **Realtime Peak Connections**: 同時に200人まで
   - **Database Size**: 500MBまで（一閃ではほとんど増えません）

## 一閃の見込みを出す

SQL Editor で次の1行を実行すると、今月の試合数と、メッセージ数の見込みが出ます。

```sql
select * from public.usage_estimate();
```

| 列 | 意味 |
|---|---|
| matches_this_month | 今月の対戦の数 |
| est_messages | メッセージ数の見込み（1試合を約1,000通として計算） |
| percent | 無料枠の何%か |
| invites_paused | 新しい招待を止めているか |

目安: 1試合はだいたい700〜1,000通です。月に2,000試合くらいまでは無料枠に収まります。

## 枠を超えそうなとき（8割を超えたら）

SQL Editor で次を実行すると、新しい招待が止まります。CPU戦・二人対戦・ガチャはそのまま遊べます。

```sql
update public.app_config set invites_paused = true;
```

再開するときは `true` を `false` にして実行します。月が変わると使用量は0に戻ります。

## 1週間だれも使わないと休止します

無料プランでは、1週間アクセスがないとプロジェクトが自動で休止します。
休止中はオンラインの画面に「通信できませんでした」と出ますが、ほかの遊び方には影響しません。
Supabase のダッシュボードを開いて「Restore」を押すと再開できます。
